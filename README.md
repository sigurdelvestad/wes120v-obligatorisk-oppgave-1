# Mitt WES120V-prosjekt

Et minimalt nettstedsprosjekt laget med [Vite](https://vite.dev/) som en del av obligatorisk oppgave 1 i faget WES120V (Web og systemutvikling) ved USN.

Prosjektet består av én enkel `index.html`, som er entrypointet til Vite. Hensikten er å øve på å sette opp en utviklingsarbeidsplass og å bygge en forståelig Git-historikk.
